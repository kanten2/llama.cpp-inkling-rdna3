# v0.1.0 · Inkling 2 Mini for Windows and Radeon RX 7900 XTX

## English

This first stable release supports **Windows x64 with one Radeon RX 7900 XTX**. It ships the inference binaries tested in preview 3 with ggml-org IQ4_NL and Unsloth Mainline_Support UD-Q4_K_M. Preview 3 users already have these prefill and decode optimizations.

At 16,384 input tokens, prefill fusion reduced mean processing time from **18.54 to 13.53 s** for IQ4_NL and **18.54 to 13.89 s** for UD-Q4_K_M (five runs per mode). In the separate IQ4_NL generation benchmark, the four-wave kernel configuration reached **54.53 tok/s** at tg768 versus **46.55 tok/s** for official b12606. [Measurements and reproduction steps](https://github.com/kanten2/llama.cpp-inkling-rdna3/tree/v0.1.0/benchmarks/inkling-rocm)

Extract the Windows ZIP and drop your GGUF onto **chat.cmd** for a local chat. Stop the chat and drop the GGUF onto **bench.cmd** to measure 768-token generation.
